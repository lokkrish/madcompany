# BMAD Company (working title)

A team of AI agents that builds apps in parallel, UI first, after BMad Method planning is done. The team runs inside your own Claude Code session, and you follow its work in a local app called HQ.

- Spec: [docs/SPEC.md](docs/SPEC.md)
- Status: design only, nothing built yet.
- The name will change before release, because BMad's trademark policy doesn't allow other projects to use "BMad" in their name ([OSS-1](docs/SPEC.md#oss-1)).
